# مشروع أندرويد: عافيتي — منظم العلاجات وقراءات
معرف الحزمة: com.alsahlany.alaa
الإصدار: 1.0.0

## طريقة بناء ملف الـ APK مجاناً عبر GitHub Actions:
1. أنشئ مستودعاً جديداً في GitHub.
2. ارفع ملف `index.html` وملف `.github/workflows/main.yml` الموجودين داخل هذه الحزمة.
3. افتح تبويب Actions في مستودعك، وبعد اكتمال البناء (حوالي دقيقتين) حمّل ملف `app-debug.apk` من قسم Artifacts.
